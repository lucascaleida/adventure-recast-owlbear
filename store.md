# Adventure Recast

Bring your Adventure Recast modules to the virtual tabletop. Read chapters and GM notes, create Owlbear scenes from module maps, share illustrations, and manage editable character sheets from the Recast panel.

## Access and requirements

Adventure Recast is currently in private beta. The GM needs an active Adventure Recast beta account and a module in their Recast library. Installing this extension does not grant beta access. Visit [Adventure Recast](https://adventurerecast.com/) for information about access and availability.

Players do not need an Adventure Recast account to open a character sheet: the GM provides a sheet-specific invitation code. Keep these codes private, as they grant access to the corresponding sheet.

## Getting started

1. Add the extension using [its manifest](https://adventurerecast.com/owlbear/manifest.json).
2. Open Recast in your Owlbear room and sign in with your Adventure Recast account as the GM.
3. Select a module to create a play copy for that room. Character sheet edits in the play copy do not change the original module.
4. Read the chapters, create scenes from maps, and show or hide illustrations and character tokens on the current scene.
5. Give each player their character sheet invitation code. Players can enter it in the Recast panel and edit their sheet.

## Features

- Chapter reading with GM notes, maps, illustrations, and character information.
- Map-based scene creation and image sharing on the Owlbear tabletop.
- Editable player character, NPC, and creature sheets.
- Character token generation and placement. AI token generation uses Adventure Recast credits; placing an existing token does not.
- Shared music and sound effects. Each participant enables audio playback for their own browser.
- Optional peer-to-peer voice and video calls, with microphone and camera controls.

## Voice, video, and browser permissions

Voice and video are optional. Participants explicitly join a call and grant browser permission before using a microphone or camera. Calls use peer-to-peer WebRTC; connectivity can vary across networks. Advanced connection settings accept a user-provided TURN configuration. The extension does not currently include a managed TURN relay.
